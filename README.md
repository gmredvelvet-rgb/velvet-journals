# Velvet Journals

A game-menu Journal experience for Foundry VTT with the Velvet AAA visual
identity. A Journal Entry becomes the hub your table actually opens: a tabbed
menu with a media dashboard, an NPC portrait gallery, a quest tracker, an
atlas with map pins, and a rich content block library — all on top of 100%
native Foundry Journal functionality.

## Requirements

| | |
|---|---|
| **Foundry VTT** | v13 or v14 |
| **Game system** | Any — nothing here is system-specific |
| **Subscription** | Optional. Every feature works on the free trial; a Patreon subscription only removes the periodic notice, and only the GM ever needs one. |

## Install

Paste this manifest URL into Foundry's *Install Module* dialog:

```
https://github.com/gmredvelvet-rgb/velvet-journals/releases/latest/download/module.json
```

Then set a Journal Entry's sheet to **Velvet Journals** (right-click the entry
→ *Configure Sheet*), or press **J** to open the Velvet Hub.

## What you get

- **Dashboard** — media cards linking to scenes, actors, items, macros, roll
  tables, playlists or external URLs. Cards group into named sections and
  support video.
- **NPC gallery** — a draggable portrait wall with search, location filters and
  a dossier modal for each character.
- **Quest tracker** — active, completed and failed quests with objectives,
  progress bars and structured rewards.
- **Atlas** — nested maps with coloured pins, each linking to NPCs, items or
  another map. Maps and pins can be hidden from players while you prep them.
- **Atlas travel** — link a Scene to a pin, then preview it, activate it, mark
  the exact arrival point and move the whole party's tokens onto it in
  formation, optionally behind a full-screen cinematic played for everyone.
- **Markdown editors** — bios, quest summaries and pin descriptions take
  Markdown, with a formatting toolbar. Existing HTML and `@UUID[…]` links keep
  working.
- **Three editions** — Classic (Belle Époque noir & gold), Survival
  (industrial field gear) and Cyber (neon holographic), plus per-journal theme
  overrides.

## Free trial and licensing

The module is never gated. Without a subscription every feature is unlocked,
and a notice appears every few minutes identifying the free trial. The GM's
notice connects to Patreon; players only ever see an informational version.

Once the GM authorises, the licence is trusted for 30 days and every
successful background check restarts that window — so an active subscriber
connects once and is never asked again. Manage it under
**Settings → Velvet Journals → Manage licence**.
